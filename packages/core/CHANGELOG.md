# `@dkcli/core`

## 0.3.0

### Minor changes

- Add version 1 theme projects with validation, content identity, revision history, artifact-bound reviews, qualification receipts, and checked token patches.
- Move retained design algorithms into public core for shared CLI and workbench execution. Correct descending Fibonacci steps and optical circle sizing.
- Add declared scene coverage, Firefox and WebKit providers, and recorded browser environment to qualification receipts. Validate bounded scene, browser, color scheme, CSS zoom, and font-fixture selections.

### Patch changes

- Apply explicitly authored viewport caps to surface proofs. Report preferred and effective widths and conservative assumptions. Preserve unresolved layout findings and proof thresholds.
- Evaluate every declared proof and report per-width results and coverage. Label source CSS audits as heuristic evidence.
- Reject arrays in scalar qualification options and receipt enum fields. Reject malformed, incomplete, stale, or contradictory evidence.
- Detect CSS contrast checks after leading whitespace, reject invalid fluid viewport ranges, and combine optical icon transforms.
- Build public declarations from current TypeScript source.
