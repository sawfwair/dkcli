# `@dkcli/core`

Framework-agnostic DesignKit math, proofs, and recipe compilation.

## What it contains

- palette and perceptual color helpers
- modular and fluid scale utilities
- component spec and recipe compilation
- proof helpers for contrast, target sizing, layout, and anchored surfaces

## Install

```bash
npm install @dkcli/core
```

## Use it for

- theme-independent DK math
- proofs and audits
- building higher-level token or component packages

For product-facing components and examples, see [`@dkcli/components`](https://www.npmjs.com/package/@dkcli/components) and the docs site at [dkcli.com](https://dkcli.com).
