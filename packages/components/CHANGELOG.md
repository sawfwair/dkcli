# `@dkcli/components`

## 0.2.5

### Patch changes

- Increase generated overlay triggers and close buttons, calendar navigation, navigation branch buttons, file chooser labels, native text inputs, and sortable grid headers to meet the 44 px project target criterion. Prevent disabled side-navigation and tree branches from expanding. Disable noninteractive stepper actions.
- Return focus to the external opener when a controlled CommandPalette closes. Focus the Popover surface when its content has no focusable descendants.
- Deliver native Button click events and observable Menu actions. Scope Select and Combobox keyboard navigation to their controls, preserve destination focus when closing, and enforce disabled behavior.
- Give field and overlay instances unique IDs that remain stable through server rendering and hydration. Preserve explicit IDs, bindings, and legacy slots.
- Keep Combobox inputs and icons within the available field width without requiring a global CSS reset.
- Let Combobox option grids shrink into their available width and wrap complete labels and descriptions with CSS zoom. Preserve option padding, fonts, selection marks, and target dimensions.
- Wrap complete Button and Badge labels within their available width while preserving short-label dimensions. Clamp anchored surfaces along their cross axis to keep open controls within the viewport.
- Keep field and tab grids within their available width at 200% CSS zoom. Scale anchored positions and surface caps consistently with root CSS zoom.
- Keep calendar day columns and complete weekday labels within their available width. Preserve day heights and report compact widths separately from the 44 px target criterion.
- Wrap long Dialog and Drawer headings. Keep the zoomed Dialog within the viewport with a scrollable body and visible close action.
- Constrain EmptyState text to shrinking grid tracks. Wrap generated Dialog triggers and reduce surface padding at narrow widths to retain usable action space.
- Keep Accordion articles and complete disclosure text within shrinking grid tracks. Reduce trigger padding at narrow widths to retain readable glyph space with CSS zoom.
- Restore InlineEdit focus after cancelling or committing keyboard edits. Animate only the fallback spinner wrapper and include its border within the declared ring size.
- Declare authored responsive surface caps in the corresponding proof specifications. Keep compact Chip and Tabs recipe dimensions unchanged.
- Require Svelte 5.20 or later. Update `@dkcli/core` and `@dkcli/tokens` to version `0.3.0`.

## 0.2.4

### Patch changes

- Hardened public CLI and package APIs.

  - Bound stored CMS sessions to their original base URL before authenticated requests.
  - Escaped CSS selectors and comments generated by `dk future`.
  - Validated component specs and used safer maps during recipe compilation.
  - Rejected unsafe CSS property names and declaration-breaking values when exporting token and recipe CSS.
  - Sanitized public component `href` props before rendering links.
  - Pinned the release workflow Changesets action to an immutable commit.

- Updated `@dkcli/core` and `@dkcli/tokens` to version `0.2.2`.

## 0.2.3

### Patch changes

- Separated the public CLI and packages from the private website and runtime.

  Vitest excludes generated component package output and uses the Svelte Vite plugin to compile component tests.
