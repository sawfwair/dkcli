# Browser regression font

The narrow-layout browser harness serves the unmodified ABeeZee regular font
from the source test server and waits for its font face before measuring.

- [Font source](https://github.com/google/fonts/blob/main/ofl/abeezee/ABeeZee-Regular.ttf)
- [SIL Open Font License](OFL.txt)
- SHA-256: `2901c8df256648cc2bb2e3afb381cb8d28e65ed3dbe11de20695ae4d5ffdeda9`

Keep the font and license together. The fixture does not establish per-glyph
fallback or general font-independent layout behavior.
