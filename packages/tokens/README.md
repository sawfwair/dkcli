# `@dkcli/tokens`

Compiled DesignKit themes, aliases, and token emitters.

## What it contains

- `createTheme` for building a `ThemeContract`
- token emitters for CSS and JSON
- semantic alias families used by DK components and docs

## Install

```bash
npm install @dkcli/tokens
```

## Use it for

- generating application theme contracts
- exporting CSS variables
- feeding theme data into `@dkcli/components`

For lower-level math, use [`@dkcli/core`](https://www.npmjs.com/package/@dkcli/core).
