# `@dkcli/tokens`

## 0.3.0

### Minor changes

- Add `createProjectTheme` to compile portable projects with body, display, and monospace font stacks, semantic token overrides, and motion presets. Validate opaque colors, finite sizes, supported units, and fluid clamp expressions.

### Patch changes

- Emit alias-to-alias references as CSS variables.
- Build public declarations from current TypeScript source.
- Update `@dkcli/core` to version `0.3.0`.

## 0.2.2

### Patch changes

- Hardened public CLI and package APIs.

  - Bound stored CMS sessions to their original base URL before authenticated requests.
  - Escaped CSS selectors and comments generated by `dk future`.
  - Validated component specs and used safer maps during recipe compilation.
  - Rejected unsafe CSS property names and declaration-breaking values when exporting token and recipe CSS.
  - Sanitized public component `href` props before rendering links.
  - Pinned the release workflow Changesets action to an immutable commit.

- Updated `@dkcli/core` to version `0.2.2`.
