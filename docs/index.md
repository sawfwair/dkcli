## What DesignKit Is

DesignKit CLI is a public package workspace for deterministic design tooling. It is not a screenshot linter and not a bag of arbitrary tokens. It is a design workbench that turns aesthetic choices into inspectable proof objects: OKLCH palettes, APCA contrast recommendations, typography rhythm, motion curves, stack layout rails, composition scores, CSS audits, and component recipe verification.

The docs site itself is built with the same principle. `pnpm docs:build` runs `scripts/generate-docs-design.mjs`, which calls the source-owned `bin/dk.js` commands and writes generated VitePress theme tokens before the site compiles.

<div class="dk-callout">
DesignKit's quiet trick is making design decisions repeatable without making the resulting interface feel mechanical. It gives you a ruler, not a cage.
</div>

## First Commands

```bash
pnpm install
pnpm dk --help
pnpm dk perfect --seed "#D96F32" --ratio perfect-fourth --motion snappy
pnpm dk palette "#D96F32" --harmony split-complementary --json
pnpm dk audit --css ./app.css
```

## Package Map

- `@dkcli/cli` ships the `dk` and `dkcli` command line tools.
- `@dkcli/core` contains framework-agnostic math, proofs, specs, and recipe compilation.
- `@dkcli/tokens` emits theme tokens and CSS/JSON artifacts.
- `@dkcli/components` provides Svelte 5 components backed by DesignKit recipes and themes.
